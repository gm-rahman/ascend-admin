CLIENT REQUIREMENTS (from .docx document)
------------------------------------------

1. Standardize Dashboard Terminology
   One approved term per concept across ALL dashboards
   (scores, roles, readiness categories, case types, alert types, statuses)

2. Standardize Workflow Status Labels
   One controlled status set per workflow type:
   alerts, performance plans, specialist follow-ups, requests, rehabilitation cases

3. Actionable Work Queues
   Priority work at top of specialist dashboards
   Analytics pushed below or removed from MVP

4. Separate PT/IM Clinical vs Performance Support
   Clearly separated sections/modules
   Clinical: rehab cases, medical docs, restrictions, authorizations, RTD
   Performance: readiness, performance plans, education, nonclinical follow-up

5. SCS Rehab Boundaries
   SCS must NOT own diagnosis, duty restrictions, medical decisions
   Label PT/IM-owned cases clearly
   Replace clinical action buttons with performance actions

6. Population Level Labels
   Every view shows: Individual Soldier, Assigned Caseload, Cohort, Unit, Organization

7. Privacy States
   Restricted, Authorization Required, Access Expired,
   Consent Required, Consent Withdrawn, Access Denied
   Consistent everywhere, never blank
